# 支持范围

适用于 `0.5.0` 开发版本。当前主要面向 VMware 虚拟机。

## 运行条件

| 项目 | 范围与要求 |
| --- | --- |
| 安装宿主 | Windows、PowerShell 7、Python 3.11+；现有安装脚本面向 Windows |
| 虚拟机端点 | 已开启且可访问的 VMware VNC 服务，满足 VNC 认证并能提供完整画面 |
| 来宾系统 | 基础截图、键鼠和画面条件不绑定特定 OS，不要求系统账号、VMware Tools 或来宾服务 |
| AI 助手 | 需要 MCP stdio、工具调用和图片结果支持；具体宿主的完整兼容性待分别验收 |
| 辅助 CLI | 随项目安装；可独立执行截图、输入、诊断等单次操作 |
| 其他 VNC 服务端 | 正式支持待定，不以协议可连接代替兼容承诺 |

已有 VMware 桌面检查覆盖 Windows 10、Windows 11 和 Ubuntu GNOME 的截图与键鼠操作，以及 Debian 文本控制台的截图与键盘操作。图形桌面的覆盖不延伸为所有应用、安装阶段或长期运行的保证。

## 连接与画面

| 能力 | 范围与条件 |
| --- | --- |
| 传输 | 直接 TCP、TLS、WebSocket 和 WSS；WebSocket 需环境已有的兼容代理 |
| 加密 | TLS／WSS 验证证书与主机名，可指定 CA；普通 TCP／WS 不加密 |
| RFB 编码 | Raw、CopyRect、Hextile、ZRLE 和 Tight 无损子集；不接受 Tight JPEG |
| 图片 | 默认输出原生尺寸 RGB8 PNG；JPEG 为显式有损选项 |
| 画面状态 | 仅发布完整帧；连接可在没有可用画面时保持打开，并报告 `display_state="unavailable"` |
| 画面条件 | 支持采样变化、参考图匹配和稳定等待；条件满足后仍需检查应用结果 |

TLS 是传输层封装，当前不支持 VeNCrypt 等新增 RFB 安全类型。PNG 保留服务端帧缓冲的 RGB8 像素；AI 宿主的图片处理和显示器色彩配置不属于像素保真范围。服务端决定实际编码和传输区域。

## 文字输入

| 通道 | 使用条件 |
| --- | --- |
| 自动选择 `auto` | 已协商 VNC UTF-8 剪贴板，或显式绑定可用的来宾 profile；都没有时在输入前拒绝 |
| VNC 剪贴板 | Unicode 文字需要服务端协商 Extended Clipboard；普通剪贴板仅支持 Latin-1 |
| 逐键 `keys` | 显式选择，结果受来宾输入法与目标应用影响；提交后截图核对 |
| 可选 VMware 来宾剪贴板 | 需要 `vmrun`、VMware Tools、来宾凭据和对应剪贴板工具 |

Linux 来宾通道可选择 X11 或 Wayland。Wayland/X11 新后端的成功粘贴路径尚未完成实机验收；使用前按目标桌面验证。配置与通道选择见 [文本输入](../references/text-input.md)。

## 显示恢复与操作限制

显示不可用时，可显式执行 `vnc_wake` 并重新截图。wake 仅尝试移动指针，不解锁，也不能保证恢复来宾强制关闭的显示。锁屏、受保护桌面和特殊应用由目标环境决定可见与可操作范围。

超时或取消不能撤回已发送的输入，工具不会自动重放。重连后使用新的连接 ID，先观察当前状态，再决定下一步。处理步骤见 [故障排查](../references/troubleshooting.md)。
